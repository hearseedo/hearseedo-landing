Why Hear See Do HomeなぜHear See Do Homeなのか

Knowing is not enough. Using it changes everything.知っているだけでは足りません。使うことがすべてを変えます。

Hear See Do Home helps learners build the confidence to use what they know, not only to recognise the right answer.Hear See Do Homeは、正しい答えを知っているだけでなく、知っていることを使える自信を育てます。

For the whole familyご家族みんなのために

Three journeys. One shared approach.3つの歩み。ひとつの考え方。

Hear See Do Home brings the family together through learning while giving each person room to grow. Every journey follows the same Hear → See → Do → Confidence approach.Hear See Do Homeは、ご家族を学びでつなぎながら、ひとりひとりが成長できる余白を大切にします。どの歩みも、聞く → 見る → やってみる → 自信、という同じ考え方に基づいています。

The Method学習メソッド

Hear → See → Do → Confidence自信

👂
Hear聞く
Listen and discover.聞いて、見つける。
👁️
See見る
Connect words with meaning.言葉を、意味とつなげる。
✋
Doやってみる
Speak, move, and try.話す、動く、やってみる。
⭐
Confidence自信
Build the courage to try again.もう一度挑戦する勇気を育てる。

Confidence before correctness. We welcome every real attempt, so learners feel safe to try and to express themselves. Support to improve comes alongside, never instead of the courage to speak. 正しさより、まず自信。どんな挑戦も歓迎します。安心して試し、自分を表現できることが第一です。上達のためのサポートは、話す勇気に寄り添う形でお届けします。

Built from real teaching experience in Japan.日本での実際の教育経験から生まれました。

Hear See Do Home was created from years of working with children, families, students, adults, schools, and educators.Hear See Do Homeは、子ども、家族、学生、大人、学校、教育関係者との長年の経験から生まれました。

The goal is simple: make learning easier to understand and easier to use in real life.目指しているのは、学びを分かりやすくし、実生活で使いやすくすることです。
